# Schemi XML ufficiali

Usati da `scripts/core/ead_export.py` per validare i file generati in `build/dati/`.

| File | Standard | Versione | Fonte |
|---|---|---|---|
| `ead3.xsd` | EAD3 (Encoded Archival Description) | 1.1.1 (2019-12-16) | https://github.com/SAA-SDT/EAD3 (ramo master) |
| `eac.xsd` | EAC-CPF (Encoded Archival Context - Corporate Bodies, Persons and Families) | 2.0 | https://github.com/SAA-SDT/eac-cpf-schema (`xml-schemas/eac-cpf/eac.xsd`, ramo master) |

Scaricati il 2 ottobre 2026. Entrambi sono mantenuti dalla Society of American Archivists
(Technical Subcommittee on Encoded Archival Standards). Per aggiornarli basta sostituire i file.
